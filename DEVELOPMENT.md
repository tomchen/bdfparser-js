# Development

Bun 1.4.2 manages dependencies; Node.js (≥ 20; CI uses 20, 22 and 24) runs the
tools.

```sh
bun install --frozen-lockfile
bun run lint        # eslint + prettier --check
bun run typecheck   # tsc --noEmit
bun run test        # vitest
bun run test:cov    # vitest with v8 coverage (text + lcov)
bun run build       # tsup → dist/
```

Commit `bun.lock` when changing dependencies. The library must keep **zero
runtime dependencies** and must not use Node.js APIs (`Buffer`, `fs`, ...)
outside `src/cli.ts`.

## Layout

| path                                         | contents                                                                                     |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `docs/SPEC-v3.md`                            | specification shared with the Python library (single source of truth)                        |
| `src/Font.ts`                                | `Font`, BDF parser (state machine), editing, `tobdf`, `tosvgfont`, wrappers for PCF / TTF     |
| `src/Glyph.ts`, `src/Bitmap.ts`              | `Glyph` (attached write-back editing) and `Bitmap`                                           |
| `src/encoding.ts`                            | charsets: `TextDecoder`-based codecs, GL detection, canonical names                          |
| `src/pcf.ts`, `src/ttf.ts`, `src/outline.ts` | PCF reader/writer, TrueType reader/writer, bitmap ⇄ outline                                   |
| `src/warn.ts`, `src/errors.ts`               | warning handler, `BDFParseError`                                                             |
| `src/cli.ts`                                 | `bdfparser` command (Node.js only)                                                           |
| `test/`                                      | vitest suites; `test/fonts/` test fonts; `test/fixtures/golden/` files generated by Python    |
| `examples/`                                  | browser and Node.js examples (no build step)                                                 |

## Builds

`tsup.config.ts` produces `dist/index.js` (ESM), `dist/index.cjs` (CommonJS),
type declarations, `dist/bdfparser.global.js` (minified IIFE exposing the
global `bdfparser`, used by `<script src>` / unpkg / jsDelivr) and
`dist/cli.js` (the `bdfparser` bin).

`test/browser.test.ts` rebuilds the IIFE bundle into a temporary directory and
runs it in a bare `vm` context (no `require`, `process` or `Buffer`) with a
fake canvas and a mocked `fetch`, to make sure the browser build stays free of
Node.js dependencies.

## Parity with the Python library

The Python implementation lives in `../bdfparser`. Behavior differences must
be justified by the spec (language idioms only). Cross-language golden files
in `test/fixtures/golden/` are generated by the Python implementation; JS
tests assert byte equality. Legacy charset tables come from the runtime's
`TextDecoder` (WHATWG Encoding), which can differ from Python's codecs for a
few code points (e.g. GBK extensions in GB2312 fonts).

## Release

1. Update `version` in `package.json`, `VERSION` in `src/constants.ts` and
   `CHANGELOG.md`.
2. Tag `vX.Y.Z` and push the tag: `.github/workflows/publish.yml` tests,
   builds and publishes to npm with provenance (secret `NPM_TOKEN`) and to
   GitHub Packages.
